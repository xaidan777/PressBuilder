# PresBuilder: ролик из текста озвучки

Ролик — папка `src/decks/<id>/`:

- `deck.json` — заголовок, текст, слайды → реплики, тайминги, правки объектов. Пишет редактор.
- `sNN_имя.ts` — код сцены слайда (`SceneDef`), `index.ts` — список сцен, `common.ts` — общие блоки ролика.

Слайд без сцены рисует заглушка (экранный текст реплик). Твоя работа — сцены. Человек в редакторе
(`npm run dev` → http://localhost:5180) правит текст, тайминги, положение и масштаб объектов и
выводит MP4 кнопкой «Вывод».

## 1. Найти или завести ролик

- «Делай тему X» — найди `src/decks/*/deck.json` по id или по `title` и прочитай его целиком.
- Прислали текст, а ролика нет — сохрани текст в файл и заведи тему:
  `node tools/new.mjs <id> <файл> --title "Заголовок" [--slides N] [--target сек]`.
  id — латиница через дефис по смыслу заголовка. Текст режется на реплики и слайды сам.
- Слайдов не больше 20: слайд — смысловой раздел (15–50 с, 3–10 реплик), графика в нём
  развивается от реплики к реплике. Если у автора есть разделы или абзацы — это готовые границы.

## 2. Что можно менять в deck.json

- Можно: `show` реплик (короткий экранный текст, 1–4 слова), `label` слайдов, осмысленные id
  реплик (только пока у ролика нет сцен — сцены ищут реплики по id).
- Нельзя: `say` (это текст озвучки автора), `target`, `format`, `objects` (правки человека), `audio`.
- Пиши файл одной записью. Открытый редактор сам перечитает его.

**Озвучка.** Человек добавляет звук кнопкой «Добавить звук» на таймлайне (файл ложится в папку ролика
как `voice.<ext>`, в deck.json — `audio`). Если просят «подогнать тайминги под озвучку»:
`node tools/align.mjs <id>` — покажет, на какие паузы голоса встают реплики; если границы сели
правильно (длины сходятся с текстом) — `--write`. Он пишет `dur` реплик, обнуляет паузы слайдов и `target`.
Текст `say` должен совпадать с тем, что звучит, иначе границы съедут. После подгонки реплики короткие:
анимацию в реплике укладывай в её `c.dur` (обычно 1–4 с), а не растягивай на «запас».

## 3. Посмотреть пример

Перед первой сценой прочитай одну-две сцены из примера — это эталон стиля и плотности:

- `src/decks/gameready-3d` — «Game-Ready 3D модели с помощью AI», 20 слайдов: окна программ (Blender,
  чат с агентом), схемы и пайплайны, 3D-модели с освещением и LOD, персонаж со скелетом и ходьбой
  по mocap, картинки и «видео» из атласа кадров. Общие блоки — в `common.ts` и `kit_*.ts`.
  `mage.ts`, `mage_walk.ts`, `dulo.ts`, `arcrace.ts`, `faces.ts`, `heroes.ts`, `sync.ts` — запечённые
  данные (вершины, анимация, тайминги слов): целиком не читай, хватит начала файла.
- Окна, курсор, печать кода, терминал, потоки, частицы, скелет — готовыми блоками в `engine/kit.ts`
  и `engine/rig.ts` (см. [references/engine.md](references/engine.md)).

## 4. Написать сцены

```ts
import { seg } from '../../engine/anim.ts';
import { reveal } from '../../engine/text.ts';
import { C } from '../../engine/theme.ts';
import type { SceneDef } from '../../engine/types.ts';

export const scene03: SceneDef = {
  id: 's03',
  render(f) {
    const { ctx } = f;
    const c = f.cue('c07'); // { t, p, on, began, done, start, dur, show, say }

    f.obj('title', { x: 150, y: 250, text: c.show, label: 'Заголовок' }, (o) => {
      const p = seg(c.t, 0, 0.6);
      if (p <= 0) return;
      reveal(ctx, o.text, 0, 0, { size: 104, color: C.text }, p);
    });
  },
};
```

`src/decks/<id>/index.ts`: `export const SCENES: SceneDef[] = [scene01, scene02, …];` — сцена
связывается со слайдом по `id`.

Правила:

- **Чистая функция времени.** Один момент — всегда один кадр: никаких `Math.random()`, `Date.now()`,
  состояния между кадрами. Случайность — `hash11` / `noise1` из `engine/anim.ts`.
- **Анимация — от реплик**, не от абсолютных секунд: `c.t` (время внутри реплики), `c.p` (0..1),
  `seg(t, start, dur)`. Тайминги меняются в редакторе, сцена должна ехать за ними.
  Реплики нет в deck.json — `f.cue()` вернёт «пустую», которая не начнётся (сцена не упадёт).
- **Всё видимое — объекты `f.obj`.** Только их человек может выделить, двигать, масштабировать и
  переписать им текст.
  - `id` уникален в слайде и стабилен (по нему хранятся правки); строки списка — `row:0`, `row:1`…
  - `x, y` — опорная точка (у текста — левый край базовой линии или центр, у группы — центр);
    внутри колбэка рисуй от `(0, 0)`. `abs: true` — внутри абсолютные координаты сцены.
  - Текст рисуй из **`o.text`**, не из исходной строки, иначе правка из редактора не применится.
    Один объект — один текст.
  - `label` — короткая русская подпись для списка объектов.
  - Вызывай `f.obj` всегда, а «ещё не появился» проверяй внутри: `if (p <= 0) return;`.
  - Объекты не вкладываются. Не объект — только декоративные вспышки на весь кадр.
- **Кадр 1920×1080.** Нижние 150 px — зона плеера YouTube, движок сам ужимает контент над ней.
  Отступы — `PAD` из `theme.ts`.
- **Кегль не меньше 46** (`MIN_TEXT`), цвета — только `C.*` из `engine/theme.ts`
  (`a(C.h1, 0.3)` — с прозрачностью). Фон рисует движок.
- **Меньше слов, больше графики.** Текст звучит в озвучке, экран его показывает, а не дублирует:
  на слайде одна короткая подпись или ничего; смысл несут схемы, иконки, графики, анимация.
- **На экране только слова из озвучки** (`show` / `say`, названные автором числа) и функциональные
  подписи графиков. Никаких придуманных заголовков, рубрик и «красивых» формулировок.
- **Картинки** — `picture()` из `engine/assets.ts` на уровне модуля, рисовать после проверки `get()`.
- Готовые блоки движка — в [references/engine.md](references/engine.md): окна, курсор, код, терминал,
  потоки, частицы, скелет, псевдо-3D, графики. Общее для ролика — в `common.ts`.
- Чужие ролики не трогай.

## 5. Проверить — коротко

1. `npx tsc --noEmit`
2. `node tools/check.mjs <id>` — гоняет все сцены без браузера: исключения, отсутствующие реплики,
   список объектов.
3. Пара контрольных кадров, если есть чем смотреть картинки. На запущенном `npm run dev`:
   `http://localhost:5180/tools/frame.html?deck=<id>&slide=s03` — 9 кадров слайда сеткой
   (`&t=42` — один кадр ролика). Снимок без окна:
   `chrome --headless=new --window-size=1920,1080 --virtual-time-budget=8000 --screenshot=out/s03.png "<url>"`
   (на Windows — `msedge`).

Не затягивай проверку: один прогон `check`, пара кадров — и отчитывайся. Человек посмотрит ролик
в редакторе сам: `http://localhost:5180/?deck=<id>`.

## 6. MP4 — только по просьбе

Обычно выводит человек кнопкой «Вывод». Если просят готовый файл: при запущенном `npm run dev`
открой в Chrome или Edge `http://localhost:5180/?deck=<id>&export=1` (Windows: `start "" "<url>"`,
macOS: `open "<url>"`, Linux: `xdg-open "<url>"`) — рендер стартует сам с форматом из deck.json →
`out/<id>.mp4`. Кусок по слайдам: `&slides=s03,s04` → `out/<id>_s03-s04.mp4`.
Вкладку не закрывать до конца рендера. Озвучка из `audio` сама попадает в MP4 (и в куски по слайдам —
с нужного места). ffmpeg берётся из `presbuilder.config.json`, `$FFMPEG`, пакета `ffmpeg-static` или PATH.
