# PresBuilder — руководство

Canvas 2D + TypeScript + Vite, интерфейс на Preact. Кадр 1920×1080 (16:9), тёмная палитра, шрифт
Sofia Sans Extra Condensed в режиме small-caps. На выходе — MP4 в папке `out/`.

Нужны [Node.js](https://nodejs.org) 22.18+ (лучше 24 LTS) и Chrome или Edge (вывод MP4 идёт через WebCodecs).

```bash
npm install
npm run dev
```

На Windows можно просто запустить `PresBuilder.bat`. Откроется <http://localhost:5180>. Больше ничего запускать не нужно: сервер редактора (сохранение
роликов, приём экспорта, сборка MP4) встроен в дев-сервер.

## Пайплайн

1. **Новая тема.** На стартовом экране — «Новая тема»: заголовок, текст озвучки, число слайдов
   (рекомендованное подставляется по длине текста), хронометраж — из текста или заданный.
   Текст сам режется на реплики, реплики раскладываются по слайдам и по времени. Ролик сразу можно
   смотреть и выводить: слайды без сцен рисует заглушка — экранный текст реплик.
2. **Сцены.** Открой папку проекта в Claude Code или Codex и скажи: «делай тему `<id>`» (подсказка
   с готовой фразой есть под сценой). Агент пишет код сцен в `src/decks/<id>/` по скиллу
   `presbuilder`; редактор подхватывает их на лету. Тему можно завести и из чата: пришли агенту
   текст и попроси «сделай из него ролик».
3. **Правки.** Текст, тайминги, положение и масштаб объектов правятся в редакторе и после работы
   агента — всё хранится в `src/decks/<id>/deck.json` и сохраняется автоматически.
4. **Вывод.** Кнопка «Вывод»: разрешение (720p / 1080p / 2K / 4K), частота кадров, хронометраж,
   битрейт → `out/<id>.mp4`.

## Редактор

| Зона | Что в ней |
| ---- | --------- |
| **Сценарий** (слева) | Слайды и реплики. Белый текст — озвучка (из неё считается время), жёлтый — что на экране. Меню «⋯»: разрезать реплику по курсору (`Ctrl+Enter`), объединить, добавить, начать новый слайд с реплики, перенести реплику в соседний слайд, переставить слайды |
| **Сцена** (центр) | Клик по объекту — выделить, тянуть — двигать (у центра кадра прилипает, `Alt` — без прилипания, `Shift` — по одной оси), угол рамки — масштаб. `Shift`+клик или рамка по пустому месту — выделить несколько и двигать вместе. Стрелки двигают выделенное на 1 px, с `Shift` — на 10. Клик по объекту в списке справа сам переводит плейхед туда, где объект виден |
| **Свойства** (справа) | Объект: X, Y, масштаб, текст, скрыть, «вернуть как в коде». Реплика: озвучка, экранный текст, длительность (из текста или вручную), пауза, темп. Слайд: паузы до/после, список объектов |
| **Таймлайн** (внизу) | Линейка, дорожка слайдов, дорожка реплик, плейхед. Границу между репликами можно тянуть — время перекатывается от одной к другой, общий хронометраж не меняется. `Ctrl+колесо` — масштаб |

Горячие клавиши: `Пробел` — пуск/пауза, `←/→` — кадр (`Shift` — секунда), `PageUp/PageDown` — слайды,
`Home/End`, `F` — на весь экран, `Ctrl+Z` / `Ctrl+Shift+Z` — отмена и возврат, `Esc` — снять выделение.

Числовые поля: стрелки вверх/вниз (`Shift` ×10) или протащить мышью за подпись поля.
Пустое поле паузы/темпа = значение по умолчанию.

## Как считается время

Длительность реплики выводится из текста (`src/engine/timing.ts`):

```
длительность = max(0.85, знаков / 14.4) + 0.12 × (число запятых и тире)
             + пауза по финальному знаку (. ? ! : ,)
             + hold
```

Поэтому дописанный текст сам раздвигает таймлайн, а анимации, привязанные к репликам, едут вместе
с ним. Если задан **хронометраж**, всё расписание пропорционально сжимается или растягивается под
него. Длительность отдельной реплики можно закрепить вручную — перетаскиванием границы на таймлайне
или полем «Длительность» (жёлтая точка на реплике; кнопка «из текста» возвращает авторасчёт).

Раскладка по времени для монтажа — когда начинается каждый слайд и реплика:

```bash
node tools/timing.mjs gameready-3d
```

## Ролики

Ролик = папка `src/decks/<id>/`:

| Файл | Что это |
| ---- | ------- |
| `deck.json` | заголовок, исходный текст, хронометраж, формат вывода, слайды → реплики, правки объектов. Пишет редактор |
| `sNN_имя.ts` | код сцены слайда (`SceneDef`): только рисование, текст и тайминги приходят из `deck.json` |
| `index.ts` | `export const SCENES: SceneDef[]` — сцены ролика; слайд связывается со сценой по `id` |

Пример в проекте: `gameready-3d` («Game-Ready 3D модели с помощью AI», 20 слайдов) — 3D-модели,
персонаж со скелетом, окна программ, картинки и «видео». Удаление темы из редактора переносит папку в `.trash/`.

Новая тема из текстового файла без редактора: `node tools/new.mjs <id> текст.txt --title "Заголовок"`.

Как писать сцены и объекты (`f.obj`) — в скилле [presbuilder](../.agents/skills/presbuilder/SKILL.md),
блоки движка — в [references/engine.md](../.agents/skills/presbuilder/references/engine.md).
Быстрая проверка сцен без браузера:

```bash
node tools/check.mjs gameready-3d
```

## Правила по тексту на экране

На экран попадает только то, что есть в озвучке: фразы реплик, числа, которые автор называет, и
функциональные подписи графиков (оси, легенды). Никаких придуманных заголовков-рубрик и «красивых»
формулировок. Кегль не меньше 46: кадр смотрят с дивана.

Нижние 150 px кадра — зона проигрывателя. Сцены верстаются в полных 1920×1080, а движок сам
ужимает контент под `SAFE_BOTTOM` из `theme.ts`.

## Озвучка

Кнопка **«Добавить звук»** в панели таймлайна (или перетащить файл на таймлайн): mp3, wav, m4a, aac,
ogg, opus, flac, webm. Файл ложится в папку ролика как `voice.<ext>`, на таймлайне появляется дорожка
с волной — её можно тянуть по времени, клик по ней перематывает. Пока голос звучит, плеер идёт по нему,
так что картинка не убегает. Меню «⋯» рядом с именем файла: заменить файл, подогнать хронометраж под
длину звука, вернуть звук к началу ролика, убрать звук. Кнопка с динамиком глушит звук только в редакторе.

Подогнать реплики под паузы голоса точно (агенту или из консоли):

```bash
node tools/align.mjs <id> --write
```

При выводе озвучка вшивается в MP4 (AAC), в том числе в куски по слайдам — с нужного места.

## Вывод в MP4

Экспорт покадровый: время кадра считается как `номер / fps`, поэтому просадки производительности
на результат не влияют. Страница кодирует кадры через WebCodecs (H.264), дев-сервер складывает
поток и собирает MP4 через ffmpeg (`-c copy`, без перекодирования). 150 секунд 1080p60 рендерятся
меньше чем за минуту; вкладку можно свернуть, но не закрывать.

ffmpeg ставится сам вместе с `npm install` (пакет `ffmpeg-static`). Свой путь можно задать в
`presbuilder.config.json` или переменной `FFMPEG`; если ffmpeg не найден, окно вывода попросит путь.

Рендер без кликов (так ролик собирает агент): открыть
`http://localhost:5180/?deck=<id>&export=1` — стартует с форматом, сохранённым в ролике.

## Структура

```
server/plugin.ts      API редактора: ролики, экспорт, ffmpeg
src/engine/           движок: тайминги, расписание, разбивка текста, рендер, объекты, экспорт,
                      типографика, графики, виджеты, иконки, псевдо-3D, фон
src/editor/           интерфейс редактора
src/decks/<id>/       ролики: deck.json + сцены
tools/                new.mjs (тема из текста), check.mjs (проверка сцен), timing.mjs (раскладка
                      по времени), align.mjs (тайминги по озвучке), frame.html (кадры сеткой)
.agents/skills/,      скилл presbuilder для Codex и Claude Code
.claude/skills/
```
